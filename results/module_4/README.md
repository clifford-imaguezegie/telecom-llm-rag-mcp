# Module 4 Results — RAG + Knowledge-Based MCP Hybrid

This directory contains the curated reproducibility artifacts for **Module 4** of the `telecom-llm-rag-mcp` repository.


## `frozen_benchmark/`

Contains the frozen Module 4 benchmark and experimental configuration. The benchmark SHA-256 is:

`c6160e33d5d2bd420ddffe7f820590c5becfa9521012d5373f06451bc9b44040`

## `formal_runs/`

Curated formal generator and independent-judge artifacts, grouped by model/runtime stage.

Use these files to validate:

- exact generator/judge model revisions;
- formal question coverage;
- natural route selection;
- retrieval and runtime metrics;
- independent evaluation completeness;
- the preserved Gemma Q16 judge failure.

Full checkpoints, duplicate artifacts and vLLM server logs are intentionally excluded from GitHub and remain in the separately archived Google Drive/Kaggle bundle.
